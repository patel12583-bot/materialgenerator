# College Attendance Management System

A professional college attendance platform for Admin/HOD, Faculty, Students and Parents.

## Current foundation
- Role-aware college portal UI
- Faculty today's lecture workflow
- Timetable-driven attendance concept
- Present / Absent / Exam Only / On Leave statuses
- Student attendance overview
- Admin master-management workspace
- Leave, proxy faculty, defaulter, reports and audit-log modules planned in the architecture

## Run
```bash
npm install
npm run dev
```

This repository is being rebuilt from the previous study-material application into an attendance-first product.
